# mini-calculatrice-C
Projet en langage C de calculatrice interactive en mode console avec menu permettant d’effectuer les opérations arithmétiques de base (addition, soustraction, multiplication et division). Le programme applique les structures conditionnelles et les boucles pour gérer les choix de l’utilisateur et afficher les résultats. 

## Fonctionnalités
- Addition
- Soustraction
- Multiplication
- Division
- Menu interactif

## Objectif
Apprendre les bases de la programmation en C :
- structures conditionnelles
- boucles
- fonctions
